# Templates

Pages HTML du site de scores, écrites avec Jinja2.

| Fichier | Rôle |
|---|---|
| `base.j2` | Gabarit commun (titre et zone de contenu) |
| `snakeHome.j2.html` | Page d'accueil avec formulaire de pseudo |
| `snakeHomeAfter.j2` | Page affichant le tableau des scores (récupérés via `/scores`) |
